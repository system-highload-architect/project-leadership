# ADR-009: Выбор C4-модели для визуализации архитектуры

**Статус:** Принято  
**Дата:** 2026-07-25  
**Автор:** Tech Lead

---

## Контекст

Для документирования архитектуры OMS необходим способ визуализации, который:
- Понятен разным аудиториям (бизнес, архитекторы, разработчики, DevOps).
- Позволяет показать систему на разных уровнях абстракции.
- Легко обновляется и хранится в репозитории.
- Интегрируется с инструментами документации (PlantUML, Markdown).

Рассматривались:
1. **C4-модель** (Context, Containers, Components, Code)
2. **Диаграммы UML** (все 14 типов)
3. **Архитектурные шаблоны** (4+1 View Model)

---

## Решение

Выбрана **C4-модель** как основной подход для визуализации архитектуры, дополненная **UML-диаграммами** для деталей реализации (Code-уровень).

**Обоснование:**

- **Многоуровневость:** C4 показывает систему от контекста до кода, что удобно для разных стейкхолдеров.
- **Простота:** Нотация интуитивно понятна даже не-техническим специалистам (Context, Containers).
- **Хранение в коде:** Диаграммы описываются текстом (PlantUML) и хранятся в репозитории, что позволяет версионировать изменения.
- **Гибкость:** C4 легко комбинируется с UML (для Component и Code уровней).
- **Инструменты:** Поддержка PlantUML, возможность генерации PNG/SVG для документации.

---

## Альтернативы

| Альтернатива | Плюсы | Минусы | Почему не выбрана |
|--------------|-------|--------|-------------------|
| **UML (все типы)** | Полнота, стандарт | Избыточен для высокоуровневого описания, сложен для бизнеса | C4 проще для коммуникации с заказчиком |
| **4+1 View Model** | Разделение на виды (логический, процессный, физический) | Менее структурирован, нет единой нотации | C4 даёт более чёткие уровни абстракции |

---

## Последствия

### Положительные
- ✅ Единый язык для всех участников проекта.
- ✅ Чёткое разделение уровней: Context → Containers → Components → Code.
- ✅ Лёгкость поддержки — диаграммы рядом с кодом.
- ✅ Возможность автоматической генерации в HTML-документацию.

### Отрицательные
- ❌ Необходимость обучения команды C4-нотации (быстрое, 1–2 часа).
- ❌ Для Code-уровня требуется дополнительная UML-диаграмма классов (но это уже есть в арсенале).

### Компромиссы
- Используем **C4 для высокоуровневой архитектуры** (Context, Containers, Components).
- Для **Code-уровня** используем **UML-диаграммы классов** (как часть C4-модели).
- Все диаграммы храним в `examples/c4/` и `examples/uml/structural/`.
