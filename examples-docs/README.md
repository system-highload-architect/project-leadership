## 1. Введение

Данная директория содержит **полный набор примеров документации** для проекта **E‑Commerce Platform**. Здесь собраны все артефакты, которые используются при разработке реального проекта: от стратегических документов до операционных инструкций и архитектурных диаграмм.

Эти примеры созданы в рамках проекта **Project Leadership** как демонстрация того, как должна выглядеть качественная документация для сложной системы. Они могут служить **шаблоном** для ваших собственных проектов.

## 3. Назначение примеров

Каждый документ в этой папке — это **живой пример**, который показывает:

1. **Как писать документы** для разных этапов жизненного цикла проекта.
2. **Как связывать документы** между собой (ADR → диаграммы → ТЗ → спринт → деплой).
3. **Как документировать архитектуру** для разных паттернов (монолит, микросервисы, EDA, serverless).
4. **Как использовать PlantUML** для генерации диаграмм (C4, ER, UML).
5. **Как применять инженерные практики** на практике.

---

## 4. Как использовать эти примеры

### Для новых проектов
1. Скопируйте нужные документы в свой проект.
2. Адаптируйте содержимое под свою предметную область.
3. Используйте структуру как основу для своей документации.

### Для обучения
1. Изучите стратегические документы, чтобы понять, как формулировать цели.
2. Изучите ADR, чтобы понять, как принимать архитектурные решения.
3. Изучите диаграммы, чтобы понять, как визуализировать архитектуру.

### Для ревью
1. Сравните свои документы с примерами.
2. Проверьте, не упущены ли важные разделы.
3. Убедитесь, что документы связаны между собой.

## 6. Технические детали

### Генерация диаграмм
Диаграммы хранятся в текстовом формате **PlantUML** (`.puml`). Для генерации SVG используйте команду:

```bash
make generate-diagrams
```

### Просмотр диаграмм
- Установите плагин PlantUML для VS Code.
- Откройте `.puml` файл и нажмите `Alt+D` для предпросмотра.

### Сборка документации
Используйте `mkdocs` для генерации HTML-версии документации:

```bash
make docs
```
