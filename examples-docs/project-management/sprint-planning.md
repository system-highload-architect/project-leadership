# План спринта: E‑Commerce Platform (MVP)

**Спринт №:** 1  
**Длительность:** 3 недели (03.07.2026 – 24.07.2026)  
**Цель спринта:** Создать работоспособное ядро системы (каталог товаров, корзина, заказы, платежи, пользователи, события, CI/CD).

---

## 1. Цель спринта

Разработать минимально жизнеспособный продукт (MVP), позволяющий:
- Покупателям просматривать каталог товаров, добавлять их в корзину и оформлять заказы.
- Менеджерам управлять товарами.
- Администраторам управлять пользователями и заказами.
- Системе обрабатывать платежи через платёжный шлюз (банковские карты, СБП).
- Публиковать события о всех изменениях в Kafka.
- Развернуть систему в dev-окружении (Kubernetes).
- Написать базовые интеграционные тесты и документацию API.

## 5. Риски и блокеры

| Риск | Вероятность | Меры смягчения |
|------|-------------|----------------|
| Нестабильность CI/CD | Средняя | Настроить локальные проверки перед пушем |
| Задержка с настройкой Kafka | Низкая | Использовать in-memory брокер для локальной разработки |
| Сложности интеграции с платёжным шлюзом | Средняя | Ранний доступ к тестовому API, мокирование |
| Сложности интеграции с UI | Средняя | Синхронизация контрактов API (OpenAPI) |
| Отсутствие опыта у команды | Средняя | Провести технические сессии по Clean Architecture, EDA, Kafka |

## 7. Критерии завершения спринта

- Все задачи S-01…S-09 выполнены и протестированы.
- Система развёрнута в dev-окружении.
- Базовый функционал работает через REST API и UI.
- События публикуются в Kafka при создании/изменении заказов и платежей.
- Интеграционные тесты проходят успешно.
- Документация OpenAPI актуальна.
- Платёжный шлюз интегрирован (тестовый режим).
